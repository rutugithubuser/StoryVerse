# StoryVerse

### OTT-Inspired Interactive Storytelling Platform

## Overview

StoryVerse is a Netflix-inspired web application that transforms memories, stories, and multimedia content into an immersive streaming-style experience. The platform recreates the feel of a modern OTT service through episode-based storytelling, dynamic content presentation, and custom media interactions.

## Features

* Netflix-style profile selection screen
* Intro splash screen with audio effects
* Dynamic hero banner image slider
* Interactive episode-based navigation
* Custom-built video player
* Keyboard shortcut support
* Episode autoplay functionality
* Next episode recommendations
* Information modal popup
* Responsive design for desktop and mobile devices

## Technologies Used

### Frontend

* HTML5
* CSS3
* JavaScript

### Deployment

* Netlify

## Implementation Highlights

* Built a custom video player with playback, mute, fullscreen, progress tracking, and autoplay support.
* Created an OTT-inspired storytelling experience with episode-based navigation and dynamic content.
* Implemented keyboard shortcuts to improve accessibility and user interaction.
* Designed responsive layouts for desktop, tablet, and mobile devices.
